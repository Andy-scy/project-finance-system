# 项目财务与合同管理分析系统

> 当前版本 **v1.1**。已部署 v1.0 的机器升级方法见 **[UPGRADE.md](UPGRADE.md)**（写给 AI Agent 的自动升级操作文档，
> 配合安装目录内的 `upgrade.bat` 一键完成，数据完整保留）。

按年度管理公司所有项目：AI 识别合同 → 人工确认建档 → 记录回款/成本/发票 →
自动计算利润与成本回收 → 质保金到期提醒 → 年度可视化经营看板 + PDF 报告。

**本地 Web 应用**：数据（SQLite 数据库 + 上传的合同文件）全部保存在自己电脑上，
通过浏览器访问 `http://127.0.0.1:8000` 使用，不依赖任何云端。

---

## 部署到其他电脑

系统文件夹**完全自包含**（便携 Python + 全部依赖 + 前端成品都在文件夹内），
目标设备只需 Windows 10/11 64位，无需联网、无需安装环境、无需管理员权限：

1. 把整个 `project-finance-system` 文件夹拷到目标电脑（U盘/局域网/网盘均可）；
   也可直接使用桌面上的「项目财务系统-部署包.zip」（已排除本机数据，解压即用）。
2. 进入文件夹，双击 `install_autostart.bat`：自动创建桌面快捷方式、注册开机自启、
   启动服务并打开浏览器。
3. 日常使用：双击桌面图标或访问 `http://127.0.0.1:8000`。

> 迁移旧数据：旧电脑运行 stop_server.bat 停止服务后，把 `backend\data`
> 整个文件夹拷到新电脑相同位置。注意本系统为单机版，各设备数据不会自动同步。

## 快速开始

**环境要求**：Windows 10/11（64位）。无需安装数据库，无需管理员权限。

### 方式一：安装为常驻服务（推荐，一次安装永久生效）

1. 双击 **`install_autostart.bat`**（仅需一次）：
   - 自动准备便携版 Python 与依赖（首次 2~5 分钟）；
   - 创建**桌面快捷方式**「项目财务管理系统」；
   - 注册**开机自启**：以后电脑开机后系统自动在后台运行，**没有任何窗口**；
   - 立即启动并打开浏览器。
2. 以后使用：双击桌面图标，或浏览器访问 `http://127.0.0.1:8000`（建议收藏书签）。

配套脚本：
- `stop_server.bat` 停止后台服务
- `uninstall_autostart.bat` 取消开机自启并删除快捷方式（数据不受影响）

### 方式二：手动启动（不安装自启）

双击 **`start.bat`**：启动服务并打开浏览器，关闭黑色窗口即停止。

### 首次使用建议

1. 打开「系统设置」→「AI 识别配置」，填入 AI API（OpenAI 兼容接口，如智谱 GLM / DeepSeek / OpenAI），
   点击「测试 AI 连接」确认可用。**不配置 AI 也可以手动录入全部数据**。
2. 「系统设置」→「数据管理」→「载入示例数据」，先体验一遍完整功能。
3. 点「新建项目」→ 拖入合同 PDF → AI 识别 → 核对确认页 → 写入项目。

## 功能总览（MVP v1.0）

| 模块 | 说明 |
|---|---|
| 经营看板 | 按年度展示：签约额/收入/利润/利润率/已到账/待到账/成本/开票/质保金，月度趋势、排名、构成等 6 组图表，自动生成「待处理事项」 |
| 项目管理 | 列表支持搜索（项目/客户/编号）、按年度/状态/质保金状态/成本回收筛选，按金额/利润/利润率/回款率排序 |
| 项目详情 | 基础信息 / 合同 / 付款计划 / 回款 / 发票 / 成本 / 利润分析 / 质保金 / AI 识别记录 / 附件，10 个标签页 |
| AI 识别 | 拖入 PDF/Word/图片/文本 → 解析 → LLM 结构化抽取 → **确认页逐项核对**（含置信度、原文页码与摘录）→ 确认后才写入 |
| 防猜机制 | AI 识别不到的字段一律「未识别/需人工确认」，绝不编造；低置信度默认不勾选写入 |
| 回款管理 | 多笔回款，关联付款节点/发票；自动累计已到账、待到账、回款率、最后一笔与下一笔预计到账 |
| 成本回收 | 累计到账 ≥ 累计成本 即视为回收，自动记录回收日期与周期（天） |
| 质保金 | 按质保期起算日+月数自动推算预计到账日；🟢已到账 🟡即将到账 🔴已到期未到账 ⚪日期未知；提前 30/7/0 天提醒，实际到账后自动停提醒 |
| 一致性检查 | 付款节点合计≠合同金额、到账超合同、开票超合同、质保金超合同、税额不自洽、亏损等自动检测 |
| 导入导出 | 项目总览/完整明细 Excel、CSV；Excel 批量导入（含模板）；年度经营分析报告 PDF |

## 技术架构

```
frontend/   Vue 3 + Element Plus + ECharts（Vite 构建，产物 dist/ 由后端托管）
backend/    Python FastAPI + SQLAlchemy + SQLite
├── app/
│   ├── models.py          9 类实体：Project / Contract / PaymentSchedule / PaymentRecord
│   │                      Invoice / CostItem(direct+indirect) / UploadedFile / ExtractionRecord / Setting
│   ├── services/calc.py   财务计算引擎（全部整数"分"运算，实时推导，不落库）
│   ├── services/alerts.py 异常检测 + 年度看板聚合
│   ├── services/extraction.py  AI 抽取（防猜约束 + 置信度 + 原文定位）与确认写入
│   └── routers/           REST API（/api 前缀）
├── data/                  app.db + uploads/（合同等原始文件，本地保存）
start.bat                  一键启动（自动引导 Python 与依赖）
scripts/smoke_test.py      核心计算冒烟测试
docs/DESIGN.md             设计文档（数据模型 / API / 页面结构）
```

**关键设计原则**

- AI 只负责"理解和提取"，程序负责"计算和校验"，用户负责"最终确认"。
- 金额一律以整数「分」存储（避免浮点误差），API 层转换为元。
- 原始录入数据与计算数据分离：利润、回收、质保金状态等全部实时计算。
- AI API Key 仅保存在后端（SQLite 设置表或环境变量 `AI_API_KEY`），前端永远拿不到明文。
- 缺失字段显示「待补充」，不阻止保存。

## 常用操作

- **改利润口径**：设置 → 按不含税（默认）/含税收入计算，全站即时生效。
- **记一笔回款**：项目详情 → 回款 → 新增回款（金额+日期即可，可关联付款节点）。
- **质保金到账**：回款类型选「质保金」或关联质保金节点，状态自动转绿。
- **年度报告**：看板右上角「生成年度报告(PDF)」，或设置页选择年度生成。

## 开发

```bash
# 后端
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

# 前端（开发模式，代理到 8000）
cd frontend
npm install
npm run dev        # http://localhost:5183
npm run build      # 产出 dist/，后端自动托管

# 冒烟测试
python scripts/smoke_test.py
```
